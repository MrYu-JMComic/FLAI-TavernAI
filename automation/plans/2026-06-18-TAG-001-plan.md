# 任务规格：角色卡标签系统增强

- **任务ID:** TAG-20260618-001
- **日期:** 2026-06-18
- **优先级:** 高（backlog → AI风月参考功能 → 角色卡标签）
- **状态:** 规划中

---

## 1. 任务目标

在现有标签 CRUD 和角色关联基础上，增强标签系统的可用性：支持彩色标签展示、标签编辑/重命名、标签搜索筛选、批量管理，以及删除前的使用情况确认，使标签系统成为角色卡分类浏览的核心入口。

---

## 2. 现状分析

### 2.1 已实现功能

| 功能模块 | 状态 | 关键文件 | 说明 |
|---------|------|---------|------|
| 标签 CRUD | ✅ 完成 | `backend/src/modules/tags.js` | createTag, deleteTag, listTags（含 usage_count） |
| 标签路由 | ✅ 完成 | `backend/src/routes/tags.js` | GET /, POST /, DELETE /:id |
| 角色-标签关联 | ✅ 完成 | `modules/tags.js` → setCharacterTags | 多对多，自动创建不存在的标签 |
| 首页热门标签栏 | ✅ 完成 | `HomeView.vue` | 随机池、选中固定、响应式数量 |
| 首页标签筛选 | ✅ 完成 | `HomeView.vue` + `characters.js` 路由 | `?tag=` 查询参数 |
| 角色表单标签编辑 | ✅ 完成 | `CharacterFormView.vue` | 搜索、创建、选择、分配 |
| 标签列表限制 | ✅ 完成 | `MAX_TAG_LIST_LIMIT = 500` | 防止过大列表 |
| 测试覆盖 | ✅ 完成 | `backend.test.js`, `tagListLimit.test.js` | CRUD、上限、字符关联 |

### 2.2 关键代码路径

```
首页标签筛选流程：
  HomeView.vue → fetchTags() → fetchCharacters({ tag: selectedTag })
    → backend characters.js route → WHERE tag IN (SELECT tag_id FROM character_tags ...)
    → 返回带 tags[] 的角色列表

角色表单标签编辑流程：
  CharacterFormView.vue → fetchTags() → 显示可用标签列表
    → 用户搜索/创建/选择 → 提交时 tags: ['tag1', 'tag2']
    → backend characters.js PATCH → setCharacterTags(db, userId, characterId, tags)
    → 自动创建不存在的标签 + 清理旧关联 + 建立新关联
```

### 2.3 差距分析

| 能力 | 现状 | 目标 |
|------|------|------|
| 彩色标签展示 | 数据库有 `color` 字段，但首页标签栏和角色卡片未展示颜色 | 标签栏、角色卡片、表单中均展示颜色圆点/背景 |
| 标签编辑/重命名 | 仅支持创建和删除，无 rename | 支持重命名标签（级联更新所有关联角色） |
| 标签颜色编辑 | 创建时可传 color，但前端无颜色选择 UI | 创建和编辑时支持颜色选择 |
| 标签搜索 | 角色表单内有 tagSearch，但标签管理无独立搜索 | 标签管理面板支持按名称搜索 |
| 批量删除 | 逐个删除 | 支持多选批量删除（含使用确认） |
| 删除确认 | 直接删除，无确认 | 显示使用该标签的角色数量，需二次确认 |
| 标签排序 | 按 usage_count DESC | 支持按名称/使用量/创建时间排序 |

## 3. 详细设计

### 3.1 后端改动

#### 3.1.1 标签重命名 API

**文件:** `backend/src/modules/tags.js`

新增 `renameTag(database, userId, tagId, newName)`:
- 验证新名称不重复
- 更新 `tags.name`
- 返回更新后的标签对象

**文件:** `backend/src/routes/tags.js`

新增 `PATCH /:id` 路由:
```js
router.patch('/:id', requireAuth, validate(updateTagSchema), (request, response) => {
  // 支持更新 name 和 color
});
```

#### 3.1.2 标签详情 API（含使用角色列表）

**文件:** `backend/src/modules/tags.js`

新增 `getTagDetail(database, userId, tagId)`:
- 返回标签信息 + 使用该标签的角色列表（id, name, avatar）
- 用于删除前确认

**文件:** `backend/src/routes/tags.js`

新增 `GET /:id` 路由

#### 3.1.3 批量删除 API

**文件:** `backend/src/modules/tags.js`

新增 `batchDeleteTags(database, userId, tagIds)`:
- 使用 savepoint 批量删除
- 返回每个标签的删除结果

**文件:** `backend/src/routes/tags.js`

新增 `POST /batch-delete` 路由

#### 3.1.4 验证 Schema

**文件:** `backend/src/validations/schemas.js`

新增:
- `updateTagSchema` — name 可选 (1-30字符), color 可选
- `batchDeleteTagSchema` — tagIds 数组 (1-50个)

### 3.2 前端改动

#### 3.2.1 API 层

**文件:** `frontend/src/api.js`

新增:
- `updateTag(id, payload)` — PATCH /api/tags/:id
- `fetchTagDetail(id)` — GET /api/tags/:id
- `batchDeleteTags(tagIds)` — POST /api/tags/batch-delete

#### 3.2.2 首页标签栏颜色展示

**文件:** `frontend/src/views/HomeView.vue`

- 标签栏中的标签 pill 展示颜色圆点（有 color 时）
- 角色卡片上的标签展示颜色背景

#### 3.2.3 角色表单标签增强

**文件:** `frontend/src/views/CharacterFormView.vue`

- 标签选择列表展示颜色圆点
- 支持在标签选择区域内直接编辑标签颜色

#### 3.2.4 标签管理面板（SettingsView 内）

**文件:** `frontend/src/views/SettingsView.vue`

在扩展管理区域新增标签管理子面板:
- 标签列表（名称、颜色、使用数量）
- 搜索筛选
- 排序切换（名称/使用量/创建时间）
- 行内编辑（重命名、改颜色）
- 多选模式 + 批量删除
- 删除前弹出确认对话框，显示使用该标签的角色列表

### 3.3 数据库

无需数据库迁移。现有 `tags` 表已有 `name`, `color`, `created_at` 字段，`character_tags` 联结表已建立多对多关联。

## 5. 验收标准

### AC-1：彩色标签展示
```
Given 用户创建了一个标签"魔法"并设置颜色为 #FF6B6B
When 在首页查看角色列表
Then 热门标签栏中"魔法"标签前显示红色圆点
And 绑定了"魔法"标签的角色卡片上展示红色标签
```

### AC-2：标签重命名
```
Given 用户有一个标签"战斗"，关联了 3 个角色
When 在标签管理面板中将其重命名为"战斗系"
Then 标签名称更新为"战斗系"
And 3 个关联角色的标签自动变为"战斗系"
And 标签管理面板列表刷新
```

### AC-3：标签管理搜索与排序
```
Given 用户有 20 个标签
When 在标签管理面板搜索框输入"魔法"
Then 仅显示名称包含"魔法"的标签
When 切换排序为"使用量降序"
Then 列表按使用数量从多到少排列
```

### AC-4：批量删除确认
```
Given 用户选中 3 个标签，其中"测试标签"关联了角色"勇者"
When 点击"批量删除"
Then 弹出确认对话框，显示"以下角色将被取消标签关联："并列出"勇者"
When 确认删除
Then 3 个标签被删除，关联关系被清理
```

### AC-5：单个删除确认
```
Given 标签"废弃"关联了角色"角色A"和"角色B"
When 点击"废弃"标签的删除按钮
Then 弹出确认对话框，显示"该标签关联了 2 个角色：角色A、角色B"
When 确认删除
Then 标签被删除
```

## 9. 风险点

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| SettingsView.vue 已有 95KB | 继续膨胀 | 标签管理面板逻辑抽离为 composable 或独立组件 |
| 标签重命名后缓存不一致 | 首页标签栏显示旧名 | 重命名后刷新标签列表 + 角色列表 |
| 批量删除误操作 | 数据丢失 | 二次确认 + 显示受影响角色 |
| 颜色选择器实现复杂度 | 前端工作量增加 | 使用预设色板（8-12 色）而非自由取色器 |
