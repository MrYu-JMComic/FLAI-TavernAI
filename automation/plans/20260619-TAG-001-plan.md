## 二、本轮迭代目标

### 2.1 标签管理页面（SettingsView 集成）

**价值**：用户需要一个集中管理标签的地方，而不是只能在创建角色时顺便创建标签。

**技术方案**：
- 在 `SettingsView.vue` 的扩展区域（与预设、Mod、正则同级）添加"标签"管理 section
- 标签列表展示：名称、颜色色块、使用次数、操作按钮（编辑/删除）
- 新增标签：名称输入 + 颜色选择器
- 编辑标签：内联编辑名称 + 颜色
- 删除标签：二次确认，显示受影响的角色数量

**需修改的文件**：
- `backend/src/modules/tags.js` — 新增 `updateTag()` 函数
- `backend/src/routes/tags.js` — 新增 `PUT /:id` 路由
- `backend/src/validations/schemas.js` — 新增 `updateTagSchema`
- `frontend/src/api.js` — 新增 `updateTag()` 函数
- `frontend/src/views/SettingsView.vue` — 添加标签管理 section

### 2.2 标签重命名与颜色编辑

**价值**：标签名和颜色需要可修改，否则创建错误只能删除重建。

**技术方案**：
- 后端 `updateTag(database, userId, tagId, payload)` — 支持更新 name 和 color
- 名称唯一性校验（同用户下不重名）
- 前端内联编辑模式：点击标签名进入编辑，支持颜色选择器

### 2.3 角色卡标签色块展示增强

**价值**：视觉上快速区分不同类型的角色卡。

**技术方案**：
- HomeView 角色卡片的标签预览增加颜色色块
- CharacterFormView 标签选择器中显示已有标签的颜色
- 使用 CSS `background-color` 内联样式渲染色块

### 2.4 多标签筛选

**价值**：组合筛选提升角色发现效率（如"魔法 + 女性"）。

**技术方案**：
- 后端 `listCharacters` 支持 `tags` 参数（逗号分隔多标签名）
- 默认 AND 逻辑：角色必须同时拥有所有指定标签
- 前端 HomeView 热门标签支持多选（toggle 模式）

**需修改的文件**：
- `backend/src/modules/characters.js` — `listCharacters` 支持多标签 AND 过滤
- `backend/src/routes/characters.js` — 解析 `tags` 参数
- `frontend/src/views/HomeView.vue` — 多标签选择 UI

## 五、技术方案概要

### 5.1 后端新增 updateTag

```javascript
// backend/src/modules/tags.js
export function updateTag(database, userId, tagId, payload) {
  const existing = database.prepare('SELECT * FROM tags WHERE id = ? AND user_id = ?').get(tagId, userId);
  if (!existing) return null;

  const name = normalizeTagName(payload.name ?? existing.name);
  const color = normalizeColor(payload.color ?? existing.color);

  // 重名检查（排除自身）
  const duplicate = database.prepare('SELECT id FROM tags WHERE user_id = ? AND name = ? AND id != ?').get(userId, name, tagId);
  if (duplicate) throw new Error('标签名已存在');

  database.prepare('UPDATE tags SET name = ?, color = ? WHERE id = ? AND user_id = ?').run(name, color, tagId, userId);

  return { id: tagId, name, color, usageCount: existing.usage_count || 0, createdAt: existing.created_at };
}
```

### 5.2 后端多标签过滤

```javascript
// backend/src/modules/characters.js — listCharacters 修改
if (tagFilter) {
```
