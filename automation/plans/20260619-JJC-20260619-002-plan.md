## 三、DoD（Definition of Done）

### 3.1 功能完成标准

1. **会话级预设绑定** ✅
   - 对话可单独绑定预设，覆盖用户默认预设
   - 绑定后重新打开对话仍保持选择
   - 解除绑定后回退到用户默认预设

2. **JSON 导入/导出** ✅
   - 支持导出单个预设为 JSON 文件下载
   - 支持从 JSON 文件导入预设（字段映射+校验）
   - 导入时处理名称冲突（自动重命名或提示覆盖）

3. **预设分类** ✅
   - 预设增加 category 字段（可选）
   - 管理界面支持按分类筛选
   - 内置默认分类：通用、角色扮演、创意写作、编程、自定义

4. **内置模板库** ✅
   - 首次使用自动创建 3-5 个内置模板预设
   - 模板覆盖常见场景：通用对话、角色扮演、翻译助手、代码助手

5. **聊天内快速切换** ✅
   - ChatView 顶部/输入区增加预设快速选择器
   - 显示当前激活预设名称
   - 一键切换，无需打开设置面板

6. **预设描述字段** ✅
   - 数据库增加 description 字段
   - 创建/编辑表单支持填写描述
   - 列表卡片展示描述摘要

### 3.2 质量标准

- 所有新增 API 端点有输入校验
- 前端组件无 console.error/warn
- 导入导出不破坏现有预设数据
- 会话级绑定不影响全局预设 CRUD

## 七、技术方案要点

### 7.1 会话级预设绑定

```
conversation_presets 表：
- conversation_id TEXT (FK → conversations.id, UNIQUE)
- preset_id TEXT (FK → presets.id)
- created_at TEXT
```

发送消息时查询链路：
1. `request.body.presetId`（客户端显式指定）
2. `conversation_presets` 表（会话绑定）
3. `getDefaultPreset()`（用户默认）

### 7.2 JSON 导入/导出格式

```json
{
  "version": 1,
  "preset": {
    "name": "角色扮演预设",
    "description": "适用于中文角色扮演场景",
    "category": "角色扮演",
    "systemPrompt": "你是一位擅长角色扮演的AI助手...",
    "temperature": 0.9,
    "maxTokens": 4096,
    "topP": 0.95,
    "frequencyPenalty": 0,
    "presencePenalty": 0
  }
}
```

### 7.3 内置模板（4个）

1. **通用对话** - 温度 0.8，通用 system prompt
2. **角色扮演** - 温度 1.0，强调角色一致性和沉浸感
3. **翻译助手** - 温度 0.3，精准翻译 prompt
4. **代码助手** - 温度 0.2，代码生成和解释 prompt

## 八、风险与注意事项

1. **数据库迁移兼容性**：新增字段需使用 `ALTER TABLE ... ADD COLUMN`（SQLite 不支持 IF NOT EXISTS for ALTER），需在 db.js 初始化中安全处理
2. **导入安全**：JSON 导入需严格校验字段类型和长度，防止注入或溢出
3. **会话绑定性能**：conversation_presets 查询应在发送消息的关键路径上，需确保有索引
4. **内置模板时机**：应延迟创建（首次访问预设页面时），而非应用启动时
