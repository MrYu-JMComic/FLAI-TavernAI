## 任务描述

在现有预设系统基础上，增加一组内置预设模板（Built-in Preset Templates）。模板覆盖常见对话场景（角色扮演、创意写作、对话助手、代码助手等），用户可在新建预设时从模板快速创建，也可直接在聊天中切换模板。

## DoD（Definition of Done）

- [ ] 后端提供内置预设模板列表 API（只读，不入库）
- [ ] 前端 PresetView 新建预设时支持"从模板创建"入口
- [ ] 内置模板包含 ≥4 个场景：角色扮演、创意写作、对话助手、代码助手
- [ ] 每个模板包含：名称、描述、system_prompt、temperature、max_tokens、top_p、frequency_penalty、presence_penalty
- [ ] 从模板创建时，表单自动填充模板参数，用户可自由修改后保存
- [ ] 现有预设 CRUD 功能不受影响
- [ ] 后端测试通过（`npm test`）
- [ ] 前端构建通过（`npm run build`）
- [ ] 编码检查通过（`node scripts/check-encoding.mjs`）

## 验收标准

1. **模板列表 API**：`GET /api/presets/templates` 返回内置模板数组，每个模板包含 `id`、`name`、`description`、`systemPrompt` 及所有 LLM 参数字段
2. **从模板创建**：PresetView 列表页显示"从模板新建"按钮，点击后展示模板卡片列表，选择后自动填充新建表单
3. **模板内容质量**：每个模板的 system_prompt 为中文，内容针对对应场景精心设计，参数值合理
4. **向后兼容**：现有预设的创建、编辑、删除、设为默认功能正常
5. **无数据迁移**：模板为代码内置，不写入数据库

## 内置模板设计（初稿）

| 模板 ID | 名称 | 描述 | temperature | max_tokens |
|---|---|---|---|---|
| `roleplay` | 角色扮演 | 沉浸式角色扮演对话，注重角色一致性和情感表达 | 0.9 | 2048 |
| `creative` | 创意写作 | 创意故事、诗歌、文案写作，鼓励想象力 | 1.1 | 4096 |
| `assistant` | 对话助手 | 通用问答助手，准确、简洁、有帮助 | 0.7 | 2048 |
| `coder` | 代码助手 | 编程辅助，注重代码质量和最佳实践 | 0.3 | 4096 |

## 风险与注意事项

- 模板为硬编码常量，不涉及数据库变更，安全无风险
- `GET /templates` 路由需放在 `/:id` 路由之前，避免被 `:id` 参数匹配
- 模板 system_prompt 内容需为 UTF-8 编码
- 不影响现有预设的 `is_default` 逻辑
