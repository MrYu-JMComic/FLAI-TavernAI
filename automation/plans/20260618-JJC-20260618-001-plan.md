# 任务规格：世界书系统

- **任务ID:** JJC-20260618-001
- **日期:** 2026-06-18
- **优先级:** 高（backlog 中标记为"新增：AI风月参考功能"第一条）

---

## 1. 任务目标

角色卡关联世界书条目，对话中出现触发词时自动将相关世界书内容注入到 AI 上下文中，用户可在前端管理世界书（创建、编辑、删除条目）。

## 2. 现状分析：已实现的功能

经过代码审查，**世界书系统已基本完整实现**。以下是已有的功能清单：

### 2.1 数据库 Schema（✅ 已完成）

| 表名 | 用途 | 关键列 |
|---|---|---|
| `world_books` | 世界书主表 | id, user_id, name, description, character_id, scan_depth, lorebook_context_percent |
| `world_book_entries` | 世界书条目 | trigger_keys, content, position, enabled, regex_mode, always_active, depth, selective, selective_logic, keys_secondary, probability, use_probability, inclusion_group, group_weight, role, sticky, cooldown, delay |
| `character_world_books` | 角色↔世界书多对多关联 | character_id, world_book_id, order_index |
| `world_book_entry_state` | 条目激活状态追踪 | entry_id, last_activated_message, last_deactivated_message, first_seen_message, sticky_remaining, was_active |

### 2.2 后端（✅ 已完成）

| 文件 | 功能 |
|---|---|
| `backend/src/modules/worldBooks.js` | CRUD 操作、触发词匹配引擎（含正则、选择性过滤、概率激活、互斥分组、递归激活）、上下文构建（at_start/before_char/after_char/at_depth 注入）、Sticky/Cooldown/Delay 状态管理 |
| `backend/src/routes/worldBooks.js` | RESTful API 路由：GET/POST/PUT/DELETE 世界书和条目，AI 草稿生成（流式/非流式） |
| `backend/src/services/worldBookAssistant.js` | AI 世界书创建助手 |
| `backend/src/routes/conversations.js` | 聊天流中集成世界书匹配和上下文注入（buildModelMessagesV2 调用） |

### 2.3 前端（✅ 已完成）

| 文件 | 功能 |
|---|---|
| `frontend/src/views/WorldBookView.vue` | 完整世界书管理界面：列表视图、详情视图、条目 CRUD、AI 创建助手、条目排序/启用/禁用 |

### 2.4 核心流程（✅ 已完成）

1. **角色卡关联世界书**：通过 `character_world_books` 关联表 + `character_id` 直接关联（双路径兼容）
2. **触发词匹配**：支持字符串匹配、正则匹配、副关键词选择性过滤、概率激活、互斥分组加权随机、递归激活（最大5层）
3. **上下文注入**：`buildWorldBookContext()` 将匹配条目按 position 拼接为系统上下文；`injectAtDepthEntries()` 将 at_depth 条目作为独立消息插入
4. **Token 预算截断**：根据 `lorebook_context_percent` 和 `contextSize` 自动截断超出预算的条目
5. **会话级世界书**：`conversations.chat_lorebook_id` 支持为单个对话绑定专属世界书

## 3. DoD（完成定义）

由于核心功能已实现，DoD 应聚焦于**验证现有实现的完整性和质量**：

### 3.1 功能验收标准

- [ ] 用户可以在世界书列表页查看所有世界书，显示条目数量统计
- [ ] 用户可以创建新世界书（名称、描述、扫描深度、上下文预算）
- [ ] 用户可以编辑世界书基本信息
- [ ] 用户可以删除世界书及其所有条目
- [ ] 用户可以在世界书详情页添加/编辑/删除/排序/启用/禁用条目
- [ ] 条目支持完整属性配置：触发词、正则模式、副关键词、选择性过滤、概率激活、互斥分组、注入位置、深度、角色、Sticky/Cooldown/Delay
- [ ] 角色卡可以通过 `character_world_books` 关联表关联多个世界书
- [ ] 对话中出现触发词时，匹配条目内容被注入到 AI 上下文
- [ ] at_depth 条目以独立消息角色（system/user/assistant）插入到指定深度
- [ ] Sticky 条目在激活后持续 N 条消息
- [ ] Cooldown 条目在失效后等待 N 条消息才能重新激活
- [ ] Delay 条目在首次出现后等待 N 条消息才开始匹配
- [ ] 互斥分组中同组条目只随机选择一个
- [ ] 递归激活：新匹配条目的内容可触发更多条目激活（最多5层）
- [ ] Token 预算自动截断超出 lorebook_context_percent 的条目
- [ ] AI 世界书创建助手可以生成完整的世界书草稿

### 3.2 后端测试

- [ ] 现有世界书路由测试全部通过
- [ ] 触发词匹配引擎覆盖：字符串匹配、正则匹配、选择性过滤、概率、分组、递归
