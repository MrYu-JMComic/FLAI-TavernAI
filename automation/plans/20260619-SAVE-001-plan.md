## 二、本轮迭代目标

### 2.1 自动存档

**价值**：用户切换对话或意外关闭页面时，自动保存当前进度，避免对话丢失。

**技术方案**：
- 在 ChatView 中监听对话切换事件（`conversationId` 变化前）
- 自动创建一个名为"自动存档 - {时间}"的存档
- 限制自动存档数量（最多保留 3 个自动存档，超出时删除最旧的）
- 自动存档标记：`saves` 表新增 `is_auto` 列（`INTEGER NOT NULL DEFAULT 0`）
- 不覆盖用户手动创建的存档

**需修改的文件**：
- `backend/src/db.js` — `ensureColumn` 迁移，添加 `is_auto` 列
- `backend/src/modules/saves.js` — `createSave()` 支持 `isAuto` 参数；新增 `pruneAutoSaves()` 函数
- `backend/src/routes/conversations.js` — 自动存档路由或参数支持
- `backend/src/validations/schemas.js` — `createSaveSchema` 新增 `isAuto` 字段
- `frontend/src/views/ChatView.vue` — 对话切换前触发自动存档
- `frontend/src/api.js` — `createSave` 传递 `isAuto` 参数

### 2.2 快速存档

**价值**：一键存档，无需打开面板，提升操作效率。

**技术方案**：
- ChatView 工具栏添加"快速存档"按钮（⚡ 图标）
- 点击后直接调用 `createSave` API，使用自动生成的名称
- 如果已有同名快速存档，覆盖更新（调用 `updateSave` 的新 `overwrite` 模式）
- 显示 toast 反馈"已快速存档"

**需修改的文件**：
- `frontend/src/views/ChatView.vue` — 添加快速存档按钮和处理函数
- `frontend/src/components/chat/ChatHeader.vue` — 如果工具栏在 Header 中

### 2.3 存档覆盖写入

**价值**：允许用户更新已有存档，而非每次创建新存档，保持存档列表整洁。

**技术方案**：
- `saves` 表的 `updateSave` 除重命名外，支持更新 `snapshot` 和 `preview`
- 前端 SaveLoadPanel 每个存档项增加"覆盖保存"按钮
- 确认对话框："用当前会话状态覆盖存档「{name}」？"
- 后端 `updateSave` 支持可选的 `snapshot` 参数：传入时重新构建快照

**需修改的文件**：
- `backend/src/modules/saves.js` — `updateSave()` 支持 `resnapshot` 参数
- `backend/src/routes/conversations.js` — `PUT /:saveId` 路由支持 `resnapshot` 选项
- `backend/src/validations/schemas.js` — `renameSaveSchema` 扩展为 `updateSaveSchema`
- `frontend/src/components/SaveLoadPanel.vue` — 添加"覆盖保存"按钮和确认逻辑
- `frontend/src/api.js` — `renameSave` 扩展为 `updateSave` 支持 `resnapshot`

### 2.4 存档元数据增强

**价值**：存档恢复时提供更丰富的上下文信息，帮助用户选择正确的存档。

**技术方案**：
- `buildSnapshot()` 扩展收集以下元数据：
  - `messageCount` — 消息总数
  - `characterName` — 当前角色名
  - `lastMessageTime` — 最后一条消息时间
  - `presetName` — 当前使用的预设名（如有）
- `buildPreview()` 增强：显示"{角色名} · {消息数}条消息 · {时间}"
- 前端 SaveLoadPanel 存档项展示增强的预览信息

**需修改的文件**：
- `backend/src/modules/saves.js` — `buildSnapshot()` 和 `buildPreview()` 增强
- `frontend/src/components/SaveLoadPanel.vue` — 存档项 UI 展示增强

### 2.5 存档备注

**价值**：用户可以为重要存档添加备注，记录剧情节点或选择原因。

**技术方案**：
- `saves` 表新增 `note` 列（`TEXT NOT NULL DEFAULT ''`）
- 创建存档时可选填备注
- 存档列表中显示备注（截断显示）

**需修改的文件**：

### 5.2 自动存档逻辑

```javascript
// backend/src/modules/saves.js — 新增
export function createAutoSave(database, userId, conversationId) {
  const count = database
    .prepare('SELECT COUNT(*) AS cnt FROM saves WHERE user_id = ? AND conversation_id = ? AND is_auto = 1')
    .get(userId, conversationId);

  // 超过 3 个自动存档时删除最旧的
  if (count.cnt >= 3) {
    const oldest = database
      .prepare('SELECT id FROM saves WHERE user_id = ? AND conversation_id = ? AND is_auto = 1 ORDER BY created_at ASC LIMIT 1')
      .get(userId, conversationId);
    if (oldest) {
      deleteSave(database, userId, oldest.id, conversationId);
    }
  }

  return createSave(database, userId, conversationId, {
    name: `自动存档 - ${new Date().toLocaleString('zh-CN', { timeZone: 'Asia/Shanghai' })}`,
    isAuto: true
  });
}
```

function buildSnapshot(database, userId, conversationId) {
  const messages = /* 现有逻辑 */;

  const conversation = database
    .prepare('SELECT character_id FROM conversations WHERE id = ? AND user_id = ?')
    .get(conversationId, userId);

  let characterName = '';
  if (conversation?.character_id) {
    const character = database
      .prepare('SELECT name FROM characters WHERE id = ?')
      .get(conversation.character_id);
    characterName = character?.name || '';
  }

  return {
    messages,
    savedAt: nowIso(),
    messageCount: messages.length,
    characterName,
    lastMessageTime: messages.length > 0 ? messages[messages.length - 1].createdAt : null
  };
}
