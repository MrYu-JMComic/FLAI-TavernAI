# AI 角色完善助手独立工作台计划

## 任务目标

将角色编辑器中的 AI 完善助手升级为独立对话页面。用户可以自由讨论、提出修改要求、查看工具执行过程和预览角色卡，持续创建、完善和维护角色。

## 范围与约束

- 复用现有模型配置、流式传输、角色工具、世界书草稿和计划审批能力。
- 会话按当前用户隔离并持久保存；新角色使用临时会话，角色创建后绑定；编辑角色自动加载该角色会话。
- 支持新建、切换和删除会话，刷新后恢复对话和草稿。
- 上下文采用稳定系统指令、角色上下文、历史对话和本轮请求的分层组成，显示上下文预算及可获取的缓存用量；缓存命中由模型服务商决定，不伪报命中。
- 提供角色卡预览弹窗，使用当前草稿，保存角色前即可预览。
- 手机端参考用户提供的 GPT、DeepSeek 布局，隐藏助手页的应用顶栏和底栏，使用紧凑会话标题栏、全屏对话和底部圆角输入区；沿用当前主题配色。
- 模型选择使用紧凑的可搜索面板，支持跨已保存网关选择模型且不改变全局网关；会话保留所选网关与模型。手机端回车换行，桌面端回车发送规则不变。
- 保留现有无关修改；不修改用户数据目录、环境配置或依赖文件，不提交、推送或部署。

## 验收标准

1. 创建角色时能够进入独立助手页面并使用独立临时会话，保存后会话可从角色再次进入。
2. 编辑角色时只列出当前用户在该角色下的会话；新建、切换、删除和刷新恢复行为正确。
3. 普通讨论能够直接回复；修改请求能够调用现有工具更新草稿；执行步骤、工具结果、错误及停止状态可见。
4. 上下文中稳定指令与本轮变化分离，历史有界；页面能查看组成与缓存相关信息。
5. 预览弹窗正确展示当前角色草稿，处理空值和长文本且不执行角色内自定义脚本。
6. 手机端助手页隐藏应用顶栏、底栏并沿用主题；手机回车换行，桌面回车发送、Shift+Enter 换行保持原样。
7. 模型选择面板限制高度、支持搜索、刷新及切换已保存网关；所选网关与模型随会话恢复，且不改变全局网关和附属技能的模型目录。
8. 所有适用检查通过；如有环境或已有问题造成失败，记录准确原因。

- 手机端使用紧凑标题栏、会话抽屉和底部输入区，隐藏应用顶栏与底栏，适配安全区和软键盘视口；抽屉提供焦点限制及 Escape 关闭。
- 使用主题内的紧凑模型选择弹窗，支持模型搜索、滚动、刷新以及已保存网关切换。后端按当前用户读取网关并使用现有网络策略；不改变全局配置，缺失或不可用的网关明确报错。
