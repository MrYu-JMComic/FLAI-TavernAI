# AI 完善助手图片上传修复计划

## 目标与范围

为独立 AI 完善助手补齐图片输入，让用户通过选择文件、粘贴或拖入图片提供角色参考；发送时向模型传递真实图片，随助手会话保存并在继续对话时恢复。复用聊天现有图片校验、资产存储及多模态供应商协议，保留现有主题和手机端换行行为。

## 执行任务

- [x] 检查助手输入、请求、会话与现有聊天图片链路，确认缺失环节。
- [x] 补齐请求校验、图片资产保存、消息历史与模型上下文中的图片内容。
- [x] 增加图片选择、粘贴、拖入、缩略图预览、移除及纯图片发送；处理失败重试和会话切换。
- [x] 清理本次涉及的纯文本限制，补充有意义的后端、前端和浏览器回归验证。
- [x] 执行构建、测试、编码及完整审核，记录结果。

## 验收标准

1. 桌面及手机端可选择支持格式的图片，发送前可预览和移除；沿用聊天每次最多 4 张、每张最大 4MB 的限制。
2. 图片可单独发送或搭配文字；模型收到真实多模态图片内容，不能只收到文件名或图片 URL 文本。
3. 刷新或重开助手会话后，已发送图片仍可见且可用于后续对话；不同用户之间的图片权限沿用现有资产规则。
4. 图片解析或发送失败时可恢复操作；会话切换不携带其他会话的待发送图片，手机端 Enter 仍为换行。
5. 普通文字、工具调用、计划模式及现有聊天图片不发生回归。
