# 状态栏自定义运行时与 Agent 改造计划

## 目标

让状态栏支持 HTML、CSS、JavaScript 和 Vue 3，保留现有内置样式与展示模板；状态栏 Agent 可独立指定模型、服务商和思考等级，并通过工具精确读取、修改变量与模板代码。

## 实施约定

- 使用现有 `template` 字段保存代码配置，兼容会话、角色蓝图、模板导入导出和快照，不新增数据库迁移。
- 可执行配置格式：`{"renderer":"runtime","framework":"vue","html":"...","css":"...","javascript":"..."}`。`framework` 支持 `html` / `vue`。
- 运行时提供 Vue 3、`api`、响应式 `variables`、`values`、`context`，支持更新变量、快捷回复、发送消息、打开设置、清理资源和监听状态变化。
- 自用代码模式允许脚本、事件、外部资源和任意 CSS；使用独立文档避免样式意外污染聊天页面，不增加逐次确认步骤。
- 思考等级使用项目已有 `THINKING_LEVELS`；空值跟随服务商，`off` 明确关闭。复用现有服务商配置与模型覆盖。
- Agent 支持读取完整状态栏、按名称更新或移除变量、编辑元数据、精确替换模板片段、修改代码分区；保留原有变量更新工具兼容性。
- 保留工作区已有未提交修改，不发布、不推送、不创建外部 PR。

## 验收

1. 现有内置样式与展示模板继续工作。
2. 会话和角色蓝图均可编辑并保存代码模式；Vue 指令、响应式变量、脚本与 CSS 可运行。
3. 代码更新能重新加载，变量更新不重建运行时；卸载清理监听与 Vue 实例，错误可见。
4. 状态栏 Agent 按选定配置调用模型；可只修改指定变量或代码片段，保留未选内容。
5. 所有必需验证有明确通过结果，或记录无法执行的具体原因。
