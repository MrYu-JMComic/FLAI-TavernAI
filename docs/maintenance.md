## 工程边界与实施顺序

沿用 Vue + composable、Express、`node:sqlite` 和 SSE。当前计划不引入 Pinia/Vuex、ORM、WebSocket、全量 TypeScript 或 i18n 重写；渐进类型检查可另行实施。

先整理测试与依赖基线，再逐个收口业务写入口和超大文件。每次围绕一个领域，先迁调用方和测试再清理旧实现，不通过平行 module/service 或放宽断言绕过失败。边界条目和关闭条件统一维护于 [架构账本](architecture.md#遗留账本)。

实现全部完成后统一执行相关验证。后端 `npm test`、前端 `test:unit/build/test:e2e`、编码检查和完整 review gate 的入口见 [项目首页](../README.md#启动与验证)。纯文档整理检查编码、Markdown 链接及差异；不因历史阶段文档而自动启动模型、迁移真实库、发布或创建 PR。

## 测试数据库隔离

2026-09-30 曾发现静态导入 `backend/src/db.js` 在模块载入时打开并迁移真实 `backend/data/flai.sqlite`。在测试正文里赋 `FLAI_DB_PATH` 来不及阻止静态 import；多个进程还可能竞态写入迁移账本。旧文档记录当时没有同日备份，不能通过重复运行已升级真实库证明旧版本升级安全。

当前代码已具备两层保护：

1. `backend/scripts/run-tests.mjs` 在启动子进程前设置临时 `FLAI_DB_PATH`，结束后清理临时目录；调用方显式设置的路径仍被保留，所以运行测试前不能把它指向真实库。
2. 测试创建独立数据库从 `db/runtime.js` 导入，不静态导入会打开 singleton 的 `db.js`；`testDatabaseIsolation.test.js` 检查启动器环境和静态导入。

新增迁移使用旧版本 fixture 的副本，验证空库、真实升级路径、重复执行、外键和失败回滚。`backend/data`、`backend/uploads` 与环境配置仍受 [AGENTS.md](../AGENTS.md) 保护；本文整理不对真实数据做恢复或迁移。启动前备份不能替代测试隔离。

## 旧 NPC 管理移除

2026-10-18 按用户要求停止原 Agent 改造并完整移除，等待另行设计：

- 移除名册、资料、记忆、行为、外观、属性/身份关系、人物物品和专属审计。
- 移除自动观察、同步、整理、修复、提示词、配置和持久任务 handler。
- 移除管理抽屉、前端 API/样式、多角色页面/队列、HMDT 人格/情绪/OOC 接口，以及依赖旧人物模型的背包、日程、遭遇战和物品奖励。
- 清理专属迁移实现、测试和旧改造计划；普通聊天、角色卡、世界书、会话记忆、状态栏、经济、场景、任务、检定、时间天气、旅行和任务奖励保留。

场景物品独立使用 `sceneItemRepository` 和 `scene_objects`。0027 只复制旧场景的世界物品，不迁移人物库存；历史表和迁移账本不清空、不改写、不重跑退休迁移。旧 v2 存档可转换恢复世界场景物品，退休领域状态不再恢复。

4 项专属回归覆盖移除契约、场景 CRUD、版本冲突、存档、历史升级与旧 API 404。实现过程未修改真实 data/uploads 或环境配置。

## AI 虚拟小镇移除

2026-10-18 按用户要求移除 AI 虚拟小镇。首页入口、专用布局、路由、前端 API、地图和素材、后端端点、模拟引擎、生成/回合/认知 AI 工具、后台生成任务、配置、校验和专用依赖均已清理；旧计划与功能文档不再保留。

新数据库不再创建 `town_*` 表及索引，0006 迁移只负责通用任务队列，既有迁移版本和校验标识保持稳定。已有数据库中的历史小镇表、记录和任务不做破坏性清理；默认 worker 不领取旧小镇任务，旧任务不再占用新任务的并发额度，新提交和失败任务重试均拒绝该类型。回归覆盖新库、历史库重复启动、旧 API 404、任务拒绝与额度隔离及保留功能的 HTTP 访问。
