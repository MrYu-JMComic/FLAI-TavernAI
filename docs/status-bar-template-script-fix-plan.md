# 状态栏自定义模板脚本修复计划

## 目标

让状态栏“自定义模板”直接支持 `<script>`，继续使用原始 HTML 模板编辑方式，保留占位符、预览和已有按钮交互。

## 范围

复用现有状态栏 iframe，覆盖模板校验、变量推断、运行与更新、角色预览及会话展示。清理拒绝脚本的旧校验分支和过时测试断言，保留普通模板与 JSON 代码模式。完整修正版只调整用户模板中的分区折叠动作和百分比宽度写法，保留其余内容。

## 执行任务

- [x] 检查模板校验、渲染、代码运行环境与现有测试，确认脚本被拒绝和移除的原因。
- [x] 将含脚本的自定义模板接入已有 iframe 运行环境；脚本源码不参与模板插值或变量推断。
- [x] 同步变量时更新模板界面，保留 DOM 监听与脚本状态；修改模板或重新运行时清理旧实例。
- [x] 更新两处编辑器提示和使用文档，保持普通展示模板及 JSON 代码配置兼容。
- [x] 根据用户提供模板修复分区折叠冲突和重复百分号，并提供完整示例。
- [x] 添加针对性回归并执行构建、测试和编码检查。

## 验收

1. 自定义模板内的脚本可以读取 DOM、调用状态栏 API，运行异常可见。
2. `{{HP}}` 等占位符随变量更新；脚本只在初始化或源码修改时执行。
3. 数据脚本不执行、不作为文字展示；JavaScript 花括号不被当作模板占位符。
4. 角色预览与会话共用渲染路径，原有模板按钮继续工作。
5. 各折叠分区互不影响，进度条宽度与颜色实际生效；示例见 [status-bar-accordion-template.html](examples/status-bar-accordion-template.html)。
